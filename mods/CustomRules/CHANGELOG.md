# Changelog

## 1.0.0
- Custom rules window in character select, set by the lobby host and synced to every player. Other mods can add rules, in their own tinted section.
- Game mode profiles: save, load/switch/unload, overwrite, rename and delete named sets of rules (Profiles tab).
- Rules: cooldown multiplier, player size (3 = normal, works like Growth/Shrink ray hits), gravity, player speed, permanent invisibility, disable ability spawning, infinite round duration (no sudden death), player bouncing mode (+ bounce on everything, bounce power), Extra Jump (+ number of air jumps; replaces the ExtraJump mod).
